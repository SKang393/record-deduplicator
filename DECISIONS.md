|---|---|---|---|---|
| **D-001** | 2026-10-31 | Repository & License | Public repo at `https://github.com/SKang393/record-deduplicator` under **Apache-2.0**. | Open-source academic reproducibility with patent-safe permissive licensing. |
| **D-002** | 2026-10-31 | Git Identity | All commits authored and pushed solely as `SKang393` (`Sungwoo Kang <200436385+SKang393@users.noreply.github.com>`), with **zero** `Co-authored-by` or agent trailers. | Matches user's existing GitHub history where commits map to `SKang393` via the GitHub noreply email. |
| **D-003** | 2026-10-31 | Core Engine Language | **Rust** (`crates/dedup-core`, `crates/dedup-cli`) using `rayon` data parallelism, deterministic sorting, and rapid string similarity crates. | Native speed, zero GC pauses, deterministic cross-platform builds for Windows and macOS, tiny binary size. |
| **D-004** | 2026-10-31 | Desktop UI Stack | **Tauri 2.0 + React + TypeScript + Vite + Tailwind CSS + `shadcn/ui` + TanStack Virtual**. | Modern, minimalist, chic zero-learning-curve UI; virtualized tables handle 50k+ records effortlessly; compiles natively to Windows (WebView2) and macOS (WKWebView). |
| **D-005** | 2026-10-31 | LLM Validation Scope | **External only (`validation/`).** The deduplicator application and core library do **not** call LLMs or require network access. | Keeps the product 100% deterministic, fast, free to run, privacy-preserving (offline-first), and reproducible for PRISMA reporting, while using LLMs + human dual-labeling strictly to validate benchmark performance. |
| **D-006** | 2026-10-31; refined 2026-11-01 | Related Reports | Distinct reports are linked as proposed typed relationships and retained. V1 has no automatic kin-suppression toggle. | A relationship is not duplicate identity or confirmed common study membership; see D-010. |
| **D-007** | 2026-10-31 | Translated Titles & Bracketed Tags | Unwrap titles enclosed wholly in `[...]` (translated titles in MEDLINE/PsycINFO) and strip only an explicit **whitelist** of bracketed artifacts (`[Abstract]`, `[Book Review]`, etc.). | Blind regex stripping of `^\[.*?\]` deletes entire translated titles. |
| **D-008** | 2026-10-31 | DOI Collision Guard | Exact normalized DOI match requires a lightweight **title sanity check** (e.g., similarity ≥ 0.60) and erratum/supplement prefix guard before auto-merging. | Prevents false merges caused by publisher/database DOI assignment errors, errata, supplements (`.s001`), or book-vs-chapter DOIs. |
| **D-009** | 2026-11-01 | Research & Library Access | Agents must **not** run autonomous keyword/topic investigations; when accessing manuscripts or university library resources, agents must use the **`aside` CLI**. | Prevents wasted quota/turns on already-completed topic design and routes institutional full-text/library lookups through the user's `aside` CLI tool. |
| **D-010** | 2026-11-01 | Normative contract | [Engine contract](docs/10-engine-contract.md) resolves conflicts in earlier notes. Full normalized DOI identity, database-namespaced accessions, trial IDs only as relationship evidence, and cluster-wide cannot-link checks are mandatory. | Prevents false merges from identifier collisions and transitive bridges; refines D-006 and D-008. |
| **D-011** | 2026-11-01 | Preservation and determinism | Immutable source bytes, ordered raw fields, field alternatives, decision replay, canonical serialization and separate runtime diagnostics. | A map of parsed tags and sorted output alone do not establish losslessness or reproducibility. |
| **D-012** | 2026-11-01 | Validation independence | Human-adjudicated held-out references; LLM suggestions advisory and external. Split by review/report family before tuning; publish uncertainty and candidate misses. | Avoids circular gold labels and pair-level leakage. Temperature zero is not determinism. |
| **D-013** | 2026-11-01 | Product scope | V1 focuses on local import, conservative deduplication, protected related reports, replayable provenance and Windows/macOS delivery. Education/Psychology is the initial evidence focus. | Differentiation is a proposed integrated workflow, not an exclusive-feature or superiority claim. |
| **D-014** | 2026-11-01 | Delivery order | Execute B01-B13 in [the plan](docs/08-development-plan.md); first useful slice is RIS to guarded exact matches to audited export. Use GPT-6.1 Terra with bounded acceptance cases. | Makes the original broad M0-M9 backlog executable without waiting for all external research/data gates. |
| **D-015** | 2026-11-01 | Claim discipline | Performance, accuracy, format coverage and installer size require measurements. PRISMA outputs are draft reporting assistance. | Foundation/build success is not algorithmic, native-app or methodological acceptance. |
